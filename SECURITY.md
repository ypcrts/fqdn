# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.5.x   | :white_check_mark: |
| < 1.5   | :x:                |

## Reporting a Vulnerability

Report suspected vulnerabilities privately through GitHub's advisory form:

<https://github.com/ypcrts/fqdn/security/advisories/new>

That opens a draft security advisory visible only to the maintainers. Please
include the fqdn version, the input that triggers the issue, and the impact you
expect. Do not open a public issue for a security report.
